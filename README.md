# 解物 · 四卷 MVP（解连环 / 走曹 · 数阵 / 七巧图 / 鲁班锁）

《解物》是一个以中国古典益智玩具为题的系列单人解谜游戏。当前发布四卷：

- **卷一「解连环」· 九连环**：把 **341 步** 的机械重复，变成一段看得见、听得懂、记得住的递归旅程。
- **卷二「走曹」· 华容道**：同一局棋，三种「一步」的定义，三个正确答案（直线 90 / 古法 81 / 单格 116）；卷内另设**数局**，3×3 / 4×4 / 5×5 数字滑块。
- **卷三「七巧图」· 七巧板**：七块板只给一个影子，不画分割线；平移、45° 旋转、平行四边形翻面，把「变换」握在手里。
- **卷四「鲁班锁」· 六子连芳**：真 3D 体素木条，只许沿三轴平移；拆得开，也装得回，键盘同样能走通。

目标不是复刻电子玩具，而是让每件器物的思维方式——递归、搜索、变换、结构——在手上真正发生一次。

### 安装与离线

把目录放到任意静态托管（HTTPS）后：

- **安装**：桌面 Chrome / Edge 地址栏可直接安装；Android 提示「添加到主屏幕」；iOS Safari 用「分享 → 添加到主屏幕」。游戏内「说明 → 带走这盏灯」可查看状态。
- **离线**：联网打开一次后，页面、图标与分享底图会进入 Service Worker 缓存；此后断网刷新仍可玩。
- **本地预览 PWA**：在本目录运行 `python -m http.server 8080`，访问 `http://localhost:8080/`。`file://` 双击模式不会注册 Service Worker，这是有意保留的降级路径。

完整上线步骤、响应头与版本回退见 `docs/03-发布与部署.md`。

|---|---|

| `Tab` | 在数字之间移动焦点 |

## 规则

以最靠近钗尖的环为第 1 环：

1. 第 1 环随时可以上、下。
2. 欲动第 k 环（k ≥ 2），须第 k−1 环在钗上，且第 1 至 k−2 环都不在钗上。

两条规则交替使用即可，永不回头。

### 华容道规则

四列五行，木块只能横向或纵向推入相邻空位，不能穿过其它棋子。
把曹操（2×2）的左上角移到底部中央 `[3,1]`，即曹操整体占据第 4–5 行、第 2–3 列，算胜。

三种「一步」都成立，只是口径不同：

| 口径 | 定义 | 横刀立马 |
|---|---|---|
| 直线步 | 一块棋沿同一方向连续滑动任意格，算一步 | 90 |
| 古法指步 | 同一块棋连续滑动，途中可转弯，算一步 | 81 |
| 单格步 | 每移动一格，算一步 | 116 |

### 数局规则

`n×n` 盘面放 `1 … n²−1` 与一个空格；每次只能把空格上下左右相邻的数字滑进空格。
目标状态按行读为 `1, 2, … n²−1, 0`（空格在右下）。

- **可解性**：把数字按行读成一列，数「前面比后面大」的对数（逆序数）。奇数阶要求逆序数为偶；偶数阶要求「逆序数 + 空格从底部数的行号」为奇。
- **生成**：从复原态随机倒走固定步数，天然落在可解的一半里；同一 seed 每次生成同一盘。
- **参考解**：启发式为曼哈顿距离 + 线性冲突，加权 A*（权重 3）。十五格的最短解本身是 NP-hard 搜索问题，廿五格更甚，因此提示与演示只保证可行，不声称最优；走得比参考解短，才是本事。

### 七巧板规则

七块板：大三角 ×2、中三角 ×1、小三角 ×2、正方形 ×1、平行四边形 ×1。

- **面积**：把七巧方边长记为 4，它可切成 16 个全等的小等腰直角三角形。大三角各 4、中三角 2、小三角各 1、正方形 2、平行四边形 2，合计 16。
- **操作**：木片可平移、按 45° 整数倍旋转；平行四边形还可以翻面。落点吸附到 0.25 格。
- **胜利**：不是「和作者摆得一模一样」，而是「所有板片都在剪影内、两两不重叠」。面积守恒保证这等价于铺满。
- **提示与演示**：提示给出一块板的参考落位与旋转角；演示按作者位姿逐块归位，不计入最佳成绩、不写进度。
- **凸形**：七块板能拼出的凸多边形恰好 13 种，1942 年由王福春与熊全治证明；本卷只取其中四个入门剪影。

### 鲁班锁规则

- **形制**：六根 2×2×6 的方木，以榫口互相咬合成一座锁。本卷使用 chinesejoinery 页面公开的实物体素数据，每根木条由若干单位立方体构成。
- **移动**：木条只能沿 x / y / z 三个坐标轴平移，**不许旋转**。每按一次方向键移动一格；被别的木条挡住时不会强行穿过。
- **拆**：从装配态开始。任意一根偏移的某个分量绝对值达到 5 格，即视为抽出并进入零件盘；只剩最后一根且已无支撑时自动拆下。
- **装**：从预设散开位开始，把木条逐根推回 `(0,0,0)`；到达即锁定，全部锁定即胜。散开位经过验证，互不重叠且每根都可达。
- **三通 / 四象 / 六合 / 九重 / 别式**：常规 2×2×6 三件鲁班锁在「只许平移」下不可解，这是三件 burr 的经典结论；本卷改用三片平板件保留三轴互锁，同样能拆能装。「四象」加穿销，「六合」「九重」叠外封，「八方」「十全」「十二楼」继续把链条加长；均为自设计教学形制，不是传统实物复原。
- **提示与演示**：按标准拆序 / 装配逆序给出下一步；演示从关卡起点播放，不计最佳成绩、不写进度。
- **成绩**：拆与装分别记录最佳步数，写入 `progress['burr-three'|'burr-six'|'burr-sixplate'|'burr-nine'|'burr-four'|'burr-eight'|'burr-ten'|'burr-twelve']`，会话独立存于 `volumes.burr.session`。

## 数学内核

状态用 9 bit 整数表示，第 i 环在 `bit(i-1)`。这套编码恰好是**二进制反射格雷码**：

```js
dist(s)      = gray2bin(s)            // 到全解的最短步数
nextDown(s)  = bin2gray(dist(s) - 1)  // 朝全解走一步
legal(s, k)  = k === 1 || (s & ((1 << (k-1)) - 1)) === (1 << (k-2))
```

512 个状态已做全量校验：每个状态的合法步集合与格雷码相邻完全一致。
任意两状态的最短距离为 `|dist(a) − dist(b)|`。

### 数局内核

数局把盘面存成 `tiles[pos]`，`0` 为空格；移动只交换空格与相邻数字。生成用固定 seed 的确定性随机从复原态倒走，可解性再用逆序数复核，不靠「多打乱几次直到能解」。
参考解用加权 A*：`f = g + 3 × (曼哈顿距离 + 线性冲突)`，节点上限按盘面分档（3×3 12 万、4×4 35 万、5×5 32 万）。4×4 起手参考解约 106 步、5×5 约 98 步，浏览器内节点数约 4.4 万，可接受。

## 开发与构建

```bash
# 构建单文件发布物，并同步 dist/ 的 manifest、sw.js 与 icons
python src/build.py

# 开发入口：逐文件加载 src，双击 dev.html 即可调试
python src/build.py --dev

# 检查 dist 是否与当前源码一致
python src/build.py --check

# 无头 Edge 烟雾测试（可用 --browser 指定 Chrome/Edge）
python tests/smoke.py

# 环命中区回归：桌面 + 390×844
python tests/hit_targets.py

# 卷二真实交互回归：键盘、拖拽、提示、弹层、落盘
python tests/huarong_ui.py

# 卷二数局回归：可解性、点击/键盘、A* 归位、选盘、切局、续玩
python tests/digital_ui.py

# 卷三七巧板回归：键盘、旋转、拖动、翻面、四关、演示、续玩
python tests/tangram_ui.py

# 卷四鲁班锁回归：三维出像素、键盘、阻挡、八关拆装、演示、续玩
python tests/burr_ui.py
```

源码顺序固定为 `core/namespace.js` → `core/store.js` → `data/volumes.js` → `data/huarong.js` → `data/digital.js` → `data/tangram.js` → `data/burr.js` → `core/hub.js` → `toys/rings/game.js` → `toys/huarong/solver.js` → `toys/huarong/sliding.js` → `toys/huarong/digital.js` → `toys/huarong/game.js` → `toys/tangram/geometry.js` → `toys/tangram/game.js` → `toys/burr/geometry.js` → `toys/burr/game.js`，由 `src/build.py` 统一内联；`dev.html` 只是把同一组文件换成 `<script src>`。构建时同时生成 `dist/manifest.webmanifest`（系列名「解物」）、`dist/sw.js`（缓存版本 `jiewu-v0.8.0-dev`）与 `dist/icons/`，`dist/` 可直接作为静态站点根目录。不引入 npm、bundler、框架或网络依赖。

存档结构见 `src/core/store.js`：`jiewu.v2` 统一存放四卷进度、会话、设置与手记；迁移只做一次，旧键只读保留 30 天。

## 考据说明
