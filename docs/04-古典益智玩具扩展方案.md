# 《解物》总方案：从九连环到四件古典益智玩具

> 续作探索、产品路线与技术方案。
> 配套：`docs/01-资料汇编.md`（九连环考据）、`docs/02-游戏开发计划.md`（第一卷立项）、`docs/03-发布与部署.md`（M4 发布手册）、`index.html`（v0.5 可玩本体）。
> 整理时间：2026-11。

---

## 0. 结论先行

1. **不做「九连环 2」，做「第一卷」。**
   把现有作品升级为系列总名 **《解物》**，九连环保留原名，作为「卷一 · 解连环」。后续每件玩具是一卷，不是资料片。

2. **主线只做四卷：九连环、华容道、七巧板、鲁班锁。**
   这四件是今人常并称的「四大古典益智玩具」。其中华容道实为 20 世纪游戏，本方案会明确标注，不把它伪装成古代发明。

3. **系列主轴不是「四件玩具」，而是「四种思维」。**

   | 卷 | 玩具 | 思维 | 算法 | 玩家离开时带走的一句话 |
   |---|---|---|---|---|
   | 一 | 九连环 | 递归 | 格雷码 / 递推 | 原来只要把 n 环化成 n−1 环 |
   | 二 | 华容道 | 搜索 | 状态图 / 广度优先 | 原来「一步」怎么定义，答案就怎么变 |
   | 三 | 七巧板 | 变换 | 等积变换 / 精确覆盖 | 原来七块可以拼出万物 |
   | 四 | 鲁班锁 | 结构 | 三维拆装 / 依赖图 | 原来锁棍一定是最后一根 |

   这条主轴同时解决三个问题：为什么是这四件、每卷终章讲什么、合集如何做教育和宣传。

4. **开发顺序：华容道 → 七巧板 → 鲁班锁。**
   - 华容道复用现有 2D/SVG/BFS 能力，2–3 周可交付，先验证「平台化」是否成立。
   - 七巧板需要新的拖拽、旋转、吸附与几何求解，4–5 周，但内容最厚、受众最广。
   - 鲁班锁是 3D 旗舰，5–6 周，风险最高，放在平台与内容都稳定之后。
   - 益智图（十五巧板）、巧环、孔明棋不进主线，做「别卷 / 展柜 / 番外」。

5. **技术底线不变：双击即开、零依赖、离线可玩。**
   源码拆模块，发布时用零依赖脚本内联成单文件；不引入 React、Three.js 或任何网络字体。

6. **本方案不做什么：**
   不做开放世界、不做联机、不做 UGC 平台、不做物理引擎级 3D、不在首年做四条产品线并行。

### 0.1 已拍板（2026-11）

| 决策项 | 结论 |
|---|---|
| 系列总名 | **《解物》**；九连环保留原名，作为「卷一 · 解连环」 |
| 第二卷顺序 | **先做华容道**，复用现有 2D / BFS 能力验证平台化 |

## 1. 为什么从「一款游戏」变成「一个馆」

### 1.1 现有资产

`index.html` 已经不只是一个玩具模拟器，它积累了一套可复用的「展陈语言」：

- **视觉**：夜玄底、单点暖光、铜金、朱砂，识别度强。
- **叙事**：五章过场 + 16 张史料卡 + 图鉴，把机械操作变成历史旅程。
- **系统**：关卡、星级、撤销、提示、演示、存档、手记、器色、高对比、全键盘、读屏。
- **承诺**：单文件、零依赖、双击即开。

这些资产每多做一件玩具，边际成本都会下降；只做九连环，则是一次性投入。

### 1.2 单一玩具的天花板

- 341 步是内容，也是门槛；通关后缺少「下一件」。
- 九连环的玩法变化有限：变体（双环、盲解、任意初态）仍是同一套动作。
- 教育场景需要「对比」：递归之外，还有搜索、几何、空间。
- 单卷的传播寿命短；合集可以互相导流、做课程、做礼盒。

### 1.3 合集的三重价值

1. **复用**：弹层、焦点栈、存档、音频、史料卡、器色、手记全部共享。
2. **交叉**：喜欢七巧板的用户会被华容道的故事吸引；教师可以按「四种思维」卖课。
3. **品牌**：从「一个九连环游戏」升级为「中国古典益智玩具馆」，才有长期货架。

### 1.4 风险

品牌稀释、工期失控、每卷质量不均。
对策：**一卷一主角，不并行；每卷独立可发布；合集只是入口，不是四倍工作量。**

## 3. 系列主轴：四件玩具，四种思维

### 3.1 为什么这条主轴重要

市面上的益智玩具合集，通常是「小游戏九宫格」：每件玩具一个入口，彼此无关。
《解物》要做的不是合集，而是**一条关于「人如何解决问题」的展览线**：

```
递归（九连环） → 搜索（华容道） → 变换（七巧板） → 结构（鲁班锁）
   降维            找路              换形              搭起来
```

每一卷的第五章都叫「格物」，讲这件玩具背后的算法，并解锁一张可交互的「算法图」：

| 卷 | 终章「格物」 | 可交互奖励 |
|---|---|---|
| 九连环 | 格雷码、512 状态、341 步 | 512 节点格雷码环（已有雏形） |
| 华容道 | 25,955 状态、BFS、一步的定义 | 状态距离热力图 / 最短路径回放 |
| 七巧板 | 16 个基本三角形、13 个凸形、精确覆盖 | 三角格 + 13 凸形收藏册 |
| 鲁班锁 | 三维坐标、碰撞、拆装依赖图 | 可旋转的拆装树 |

这张「算法图」是合集真正的收藏品：它把「我通关了」变成「我看懂了」。

### 3.2 四卷的「一句话」

- **卷一 · 解连环**：把 341 步的机械重复，变成一段看得见的递归。
- **卷二 · 华容道**：同一局棋，三种「一步」的定义，三个正确答案。
- **卷三 · 七巧板**：七块板，十三种凸形，无数种人间。
- **卷四 · 鲁班锁**：六根木头，三轴相扣，最后一根叫「锁」。

## 4. 推荐路线

### 4.1 四卷 + 三别卷

| 层级 | 卷 | 玩具 | 定位 | 发布方式 |
|---|---|---|---|---|
| 主线 | 卷一 | 九连环 | 递归；已有 v0.5 | 现有作品，改名入馆 |
| 主线 | 卷二 | 华容道 | 搜索；最快验证平台 | 独立发布，再入合集 |
| 主线 | 卷三 | 七巧板 | 变换；内容与受众最广 | 独立发布，再入合集 |
| 主线 | 卷四 | 鲁班锁 | 结构；3D 旗舰 | 合集 2.0 |
| 别卷 | A | 益智图（十五巧板） | 图形语言；七巧板 DLC | 卷三发售后 1–2 月 |
| 别卷 | B | 巧环 | 拓扑；阮氏家族故事 | 实验展柜，3 关 |
| 别卷 | C | 孔明棋（独立钻石） | 逆向搜索；西学东渐对照 | 免费小展柜 |

### 4.2 为什么先做华容道

- **技术复用最高**：4×5 网格、SVG 方块、BFS、提示、演示，和九连环的「状态机 + 求解器 + 渲染分层」同构。
- **交付最快**：2–3 周可以做完一卷，足以验证平台化、存档迁移、合集入口是否成立。
- **考据故事强**：它不是古代玩具，而是 1930 年代中国街头、1932 英国专利、1964 《科学美国人》三条线交汇的现代物。这个「反常识」本身就是内容。
- **可验证性极强**：25,955 个状态可全量枚举；「横刀立马」的 81 / 90 / 116 三种计步口径可以做成玩法的一部分。

### 4.3 为什么七巧板第二

- 它需要全新的**拖拽 + 旋转 + 吸附 + 精确覆盖**引擎，不能靠华容道的网格复用。
- 但它内容最厚：燕几、蝶几、七巧图、七巧桌、七巧攒盘、外销史，足够撑五章。
- 它的用户最广：不玩硬核解谜的人也会想拼一只鹅。
- 它的失败成本可控：即使鲁班锁延期，七巧板也能独立成立。

### 4.4 为什么鲁班锁最后

- 3D 的交互、遮挡、拾取、性能、晕动，全是新风险。
- 它最适合做「合集预告片」的高光，但不适合做第一块试验田。
- 先用 1 周做技术 spike，验证 Canvas 等轴测下的拾取、遮挡与键盘操作；真 3D 是硬指标，不设 2.5D 降级路线。

### 4.5 不推荐先做

| 候选 | 原因 |
|---|---|
| 鲁班锁首发 | 3D 风险 + 无平台壳，失败会拖垮整个系列（v0.8.0 已改：平台壳与 3D spike 完成后，作为第四卷真 3D 加入） |
| 巧环首发 | 绳结/穿越的真实感极难数字化，容易做成「点下一步」的假解谜 |
| 十五子棋 / 汉诺塔 | 太常见，没有文化护城河；可做教育模式小游戏 |
| 益智图首发 | 弧形精确覆盖成本高，内容偏窄；适合作为七巧板 DLC |

## 5. 各卷方案

### 5.1 卷二 · 华容道

#### 一句话

**同一局棋，三种「一步」的定义，三个正确答案。**

#### 规则与计步口径

4 列 × 5 行棋盘，10 块：曹操 2×2、关羽 2×1 横、四将 1×2 竖、四卒 1×1。目标：把曹操移到下方出口。

「一步」有三种合理定义，必须让玩家看见差别：

| 口径 | 定义 | 横刀立马最少步数 | 用途 |
|---|---|---:|---|
| **直线步**（默认） | 一个棋子沿一个方向连续滑动任意格，算一步 | **90** | 游戏默认计分、星级 |
| **古法 / 指步** | 一个棋子可连续滑动并转弯，算一步 | **81** | 「古法挑战」记录 |
| **单格步** | 每移动一格算一步 | **116** | 数据分析、硬核榜 |

> 这不是三个版本，而是同一局面图的三种走法定义。文献值见 Hordern《Sliding Block Puzzles》与 Tmütze 的 Klotski 表；本方案按「直线步」复算得 90，状态数 25,955，与文献一致。

#### 状态与求解

- 状态：10 个棋子的左上角坐标；同形棋子（四将、四卒）可互换，按组排序做规范化。
- 状态空间：**25,955** 个可达状态（全棋盘 65,880 个摆放，其中 898 个连通分量）。
- 求解：从「曹操到达底部中央」的目标集合反向 BFS，得到全状态距离表；提示 = 走一步后距离减一的邻居；O(1) 查询。
- 三种口径分别建三张距离表：单格边、直线边、指步边。
- 构建时预计算 16 个经典布局的最优解；距离表本身由全状态图共享，不按布局重算；每日题在运行时 BFS，限制在目标所在连通分量。

#### 关卡

| 关卡 | 布局 | 作用 |
|---|---|---|
| 教学 · 小试 | 简化 4×5（曹操 + 2 卒 + 出口） | 90 秒内学会「滑块只能推向空位」 |
| 横刀立马 | 经典 | 主线第一关；三种计步对照 |
| 插翅难飞 | 经典 | 第一道「下方腾挪」难题 |
| 层层设防 | 经典 | 长局 |
| 水泄不通 | 经典 | 长局 |
| 守口如瓶 | 经典 | 结构辨识 |
| 屯兵东路 | 经典 | 侧翼 |
| 兵临曹营 | 经典 | 对称 |
| 齐头并进 / 兵分三路 | 经典 | 多横块 |
| 雨声淅沥 / 桃花园中 | 经典 | 节奏变化 |
| 一路进军 / 捷足先登 | 经典 | 短局 |
| 围而不歼 / 过五关 / 小燕出巢 | 经典 | 挑战 |
| 每日一题 | 随机可达状态 | 长线 |

> 除「横刀立马」外，其余布局的最优步数不在文档里写死，构建时由 BFS 计算并写入关卡数据；避免抄错。

#### 数局（v0.6.1 追加）

卷二内新增「数局」，与木局并列，不改四卷格局：

- **盘面**：3×3（九宫）、4×4（十六宫，默认）、5×5（廿五宫）；`1 … n²−1` 按行排好、空格在右下即胜。
- **生成**：固定 seed 从复原态倒走 `depth` 步（3×3 40 步、4×4 120 步、5×5 160 步），天然可解；发布前再用逆序数 + 空格行号复核。
- **参考解**：曼哈顿距离 + 线性冲突的加权 A*（权重 3）；节点上限 3×3 12 万、4×4 35 万、5×5 32 万。只称「参考解」，不声称最优。
- **存档**：`volumes.huarong.sessionDigital` 独立保存；进度键 `digital-9` / `digital-16` / `digital-25`。
- **交互与无障碍**：点击、方向键、`Enter`/`Space`、撤销、重置、提示、演示；与木局共用卷二外壳与弹层焦点栈。

> 设计意图：木局训练「状态图 + BFS」，数局训练「启发式 + A*」。同一卷内看见两种搜索，才算把「搜索」讲完整。

### 5.2 卷三 · 七巧板

#### 一句话

**七块板，十三种凸形，无数种人间。**

#### 规则

- 用全部 7 块，拼出目标剪影；块与块不重叠、不留缝、不越界。
- 可平移、旋转 45° 的整数倍；平行四边形可翻面。
- 目标只给剪影（影子模式），不画分割线；提示才显示某一块的落位。

#### 数学内核

- 标准七巧板正方形可切成 **16 个全等的小等腰直角三角形**（每块面积 1）。
- 七块分别是：大三角 ×2（每块面积 4）、中三角 ×1（2）、小三角 ×2（1）、正方形 ×1（2）、平行四边形 ×1（2），合计 16。
- 所有板块都是这些小三角形的整数并集；坐标放大 2 倍后用整数表示，旋转/镜像预计算 8 个朝向。
- 拼图 = 目标三角形的**精确覆盖**：每个基本三角形恰好被一块覆盖一次。
- 数学彩蛋：七块板能拼出的凸多边形恰好 **13 种**（Wang & Hsiung, 1942）——这是终章「格物」的收藏目标。

#### 状态与求解

- 目标剪影先栅格化为基本三角形集合。
- 对每块、每个朝向、每个平移，生成所有「完全落在目标内」的放置；用精确覆盖（DLX / 回溯）求解。
- 7 块、每块几十到几百个放置，求解通常在毫秒级；可找出多个解，用于「一图多解」提示。
- 提示：从当前合法解中取一块尚未放对的，显示其目标位姿；不直接替玩家拼完。
- 自由模式：无目标，只做吸附与合法性检查；完成后可存为「手记」缩略图。

#### 关卡

| 组 | 数量 | 内容 | 来源 / 说明 |
|---|---:|---|---|
| 教学 | 3 | 两块成方 → 七块成方 → 第一只鹅 | 渐进教学 |
| 器物 | 12 | 桌、椅、壶、船、桥、灯 | 传统七巧图题材，重绘 |
| 动物 | 15 | 鹅、鱼、兔、猫、马、鸟 | 传统题材 |
| 人物 | 10 | 渔翁、仕女、童子 | 吴友如风格参考，重绘 |
| 文字 | 10 | 福、寿、春、喜、解 | 受益智图「以图配字」启发 |
| 山水 | 10 | 山、水、舟、亭 | 文人画构图 |
| 合计 | 60 | 首发可先做 40，余下更新 | 每关 3 星 + 「一图多解」徽章 |

#### 星级

七巧板没有「唯一最优步数」——同一剪影常有多个解，且「步」不等于「移动格数」。因此：

#### 章节与史料

| 章 | 年代 | 史料锚点 | 考据注 |
|---|---|---|---|
| 一 · 燕几 | 北宋 | 黄伯思（1079–1118）设计六件/七件案几，《燕几图》 | 「燕几」是宴客案几，不是玩具 |

#### MVP 落地（v0.7.0）

实际首发的卷三没有走「基本三角形精确覆盖」的原计划，而是用连续多边形做几何判定，原因与结果都记录在这里：

- **棋盘**：12×8 基准单位，`unit=80`；上方剪影区 `x 4..8, y 0..4`，下方木片区 `y 4..8`。SVG `viewBox 0 0 960 640`。
- **七块板**：大三角 ×2、中三角 ×1、小三角 ×2、正方形 ×1、平行四边形 ×1；按类型分色，锚点取母形第一个顶点。
- **位姿**：`{x, y, rot, flip}`；先翻面、再旋转、最后平移；旋转吸附到 45° 整数倍，平移吸附到 0.25 格。
- **目标剪影**：把参考解七块板的多边形合并成一个 SVG path 一次性填充，外缘用 `drop-shadow` 表现，天然没有内部接缝；不画分割线。
- **胜利判定**：所有板片都在剪影内（采样点包含）且两两不重叠（SAT）；七块面积合计等于目标面积，因此这等价于铺满。不比对作者位姿，允许多种解法。
- **四关**：小方（2 小三角）、大方（2 大三角）、大三角（2 大三角）、七巧方（7 块）；每关目标位姿与文案在 `src/data/tangram.js`。
- **几何内核**：`src/toys/tangram/geometry.js` 提供面积、质心、位姿变换、点包含、SAT 重叠、剪影包含采样、覆盖判定与吸附；全部纯函数，便于测试。
- **提示与演示**：提示给出一块板的参考落位、旋转角与是否翻面；演示按作者位姿逐块动画归位，不计最佳、不写进度。
- **存档**：`jiewu.v2 / volumes.tangram.session`；进度键 `tangram-two-small` / `tangram-two-large` / `tangram-two-triangle` / `tangram-seven-square`。
- **回归**：`tests/tangram_ui.py` 41 项；四关作者位姿均通过 `coversTarget`，拖动/键盘/旋转/翻面/提示/演示/选关/说明/馆往返/续玩全过。

> 后续若扩到 40 关，可在保留连续几何判定的同时，引入「参考解 + 多解搜索」；精确覆盖仍适合做关卡生成与验证工具，但不再作为运行时唯一判据。

### 5.3 卷四 · 鲁班锁

#### 一句话

**六根木头，三轴相扣，最后一根叫「锁」。**

#### 规则

- 拆：把六根（或九/十二根）木条按顺序拆开，不能硬拔。
- 装：从散件装回整体，最后一根「锁棍」插入后结构自锁。
- 只允许沿三个坐标轴平移；不允许旋转木条（真实鲁班锁的拆装以平移为主）。
- 拆和装是两种模式；拆完自动进入「装」的挑战。

#### 数学内核

- 每根木条是 6×2×2 的长方体，带不同榫口；六根分别在 x/y/z 三轴，两两垂直。
- 用体素（voxel）表示占用；一次移动 = 沿一个轴平移 1 格，若目标体素全空则合法。
- 拆装图：状态 = 六根木条的位移；边 = 合法平移；求解 = 从装配态到「全部散开」的 BFS/DFS。
- 对 6 根锁，状态空间可控；对 12 根锁，用「先找可拆件、递归分解」的拆装树，而不是全量 BFS。
- 「锁棍」：通常是榫口最少、最后插入的那根；它在拆解时通常最后才能动。

#### 状态与求解

- 构建时对每个关卡跑一次拆装求解，保存一条合法拆解序列与一条装配序列。
- 提示 = 当前状态下「可移动且不破坏可解性」的下一步；用预计算序列 + 实时合法性校验。
- 若玩家把件移到序列外，实时 BFS 重算到最近的可拆状态；6 根锁可接受，12 根锁用启发式 + 缓存。
- 关卡数据只存「木条榫形 + 初始装配」，解由构建脚本生成，避免手写错。

#### 关卡

| 关卡 | 根数 | 作用 |
|---|---|---|
| 教学 · 三通 | 3 | 理解「三轴相扣」 |
| 六子连芳 | 6 | 经典；唐芸洲 1889 记载的形制 |
| 六合（自设计） | 6 | 平板进阶；在三通上叠压盖、边销、边梁，练外锁次序 |
| 九重（自设计） | 9 | 长链；在六合上再叠顶盖、压销、上梁，练长依赖链 |
| 四象（自设计） | 4 | 穿销；底板多开销孔，先拔销再抽板 |
| 八方（自设计） | 8 | 六合加顶梁、外销 |
| 十全（自设计） | 10 | 九重加天锁 |
| 十二楼（自设计） | 12 | 九重加顶封、上销、中销 |
| 梅花锁 | 6 | 榫口变化 |
| 球锁 / 桂花球子 | 6（弧形） | 唐芸洲 1890「桂花球子」；3D 弧形近似 |
| 好汉锁 | 6 | 长局 |
| 中字锁 | 6 | 结构辨识 |

#### MVP 验收（v0.8.0）

- 真 3D：Canvas 2D 自写正交投影、面法线着色、画家算法与屏幕面片拾取；未引入 Three.js。
- 六根木条采用 chinesejoinery 公开体素数据；标准拆序 `1 +x → 1024 +z → 975 +y → 824 +z → 928 +x → 256 +z` 与装配逆序均验证无碰撞。
- 三件 2×2×6 方木在纯轴向平移下无解，改用三片平板「三通」保留三轴互锁；拆 `A -z → B +x → C +x`，装为其逆序。
- 六片平板「六合」为自设计进阶关：拆 `W6 +z → W5 +y → W4 +z → W1 -z → W2 +x → W3 +x`，装为其逆序；装配态与散开位均无重叠。
- 九片「九重」为自设计长链关：拆 `O1 +y → O2 +z → O3 +y → W6 +z → W5 +y → W4 +z → W1 -z → W2 +x → W3 +x`，装为其逆序；装配态与散开位均无重叠。
- 四片「四象」为自设计穿销关：拆 `D4 -x → D1 -z → D2 +x → D3 +x`；底板多开销孔，穿销不退则底板不动。
- 八片「八方」拆 `E1 +y → E2 +z → W6 +z → W5 +y → W4 +z → W1 -z → W2 +x → W3 +x`；十片「十全」在九重前加 `T1 +z`；十二片「十二楼」再加 `L1 +y → L2 +y → L3 +z`。三者装配均取逆序，装配态与散开位无重叠。
- 拆（偏移分量绝对值 ≥ 5 格进零件盘）与装（散开位推回 `(0,0,0)` 即锁定）两种模式均可键盘走通。
- 六根散开位 `1:(5,0,0)`、`928:(5,0,5)`、`1024:(0,0,5)`、`824:(0,5,5)`、`975:(0,5,0)`、`256:(5,5,0)` 互不重叠且可达。
- 视角拖动旋转、松手吸附 90° 档位；`Q` `E` 每次 90°；尊重 `prefers-reduced-motion`。
- 提示 / 演示按预计算序列播放，演示不计成绩；拆装分别记最佳步数，存于 `volumes.burr`。
- 回归：`tests/burr_ui.py` 140 项全过（含四象 / 八方 / 十全 / 十二楼拆装、指针点选 / 轴向拖动与三档窄屏视口）；`tests/smoke.py` 68 项升至 v0.8.0-dev。

### 5.4 别卷 A · 益智图（十五巧板）

**定位**：七巧板 DLC / 独立小卷，不占主线。

- **形制**：15 块 = 1 平行四边形 + 2 半圆 + 4 弧角 + 8 多边形；1+2+4+8=15，取《易》太极、两仪、四象、八卦之数。
- **历史**：童叶庚（1828–1899）1862 年成稿，1878 年刊《益智图》；1885《益智续图》；1892《益智图千字文》；恭亲王 1893 题「操觚新格」；溥仪旧藏今在故宫；商务印书馆 1932 年遭炸毁。
- **玩法**：与七巧板同一套拖拽/旋转/吸附，增加弧形块；目标包括器物、人物、山水、文字。
- **技术**：复用七巧板精确覆盖；弧形块用高分辨率栅格 + 面积/覆盖判定，允许极小容差；先做 20 关验证，不一次做 1000 字。
- **差异**：七巧板是「几何」，益智图是「图形语言」——用 15 块拼字、配诗，是更强的文化表达。
- **风险**：弧形精确覆盖与作者成本；如果 20 关验证不顺，降级为「展柜 + 3 个可玩图」。

### 5.5 别卷 B · 巧环

**定位**：实验展柜，3 关，不做全卷。

- **历史**：余崇恩（一作俞崇恩）1958 年《巧环》小册子，介绍 24 种巧环；苏州老艺人阮刘琪（1900–1962）制作并创制塔环、壶环、猫环、飞机环等；1997 年后阮根全恢复制作。
- **玩法**：金属丝与环的穿越；玩家拖动环/柄，寻找「穿过」的路径。
- **技术难点**：真实绳结/穿越的碰撞与拓扑极难；不建议做物理绳。
- **推荐做法**：把每个巧环抽象成「若干次合法穿越」的序列；玩家拖到正确位置才触发穿越动画，错误位置回弹。它更像「立体迷宫」，不是「绳物理」。
- **风险**：容易被硬核玩家说「假」。因此只做 3 关、明确标注「展柜式演绎」，不承诺全真模拟。
- **价值**：阮氏家族故事极好，可做一页「口述史」；即使不玩，也值得看。

### 5.6 别卷 C · 孔明棋（独立钻石）

**定位**：免费小展柜 / 每日一题，西学东渐对照。

- **形制**：33 孔，32 子，中央留空；跳吃，目标最后剩一子（最好在中心）。
- **历史**：1687 年法国《文雅信使》最早书面记载；相传与巴士底狱囚犯有关（传说）；中国称「孔明棋」「独立钻石」「单身贵族」，但**不是诸葛亮发明**。
- **玩法**：标准 33 孔棋盘；每日一题；最少 31 步的「完美局」。
- **技术**：位棋盘 + DFS/IDA*，33 位整数；状态空间大但单局可解；预计算每日题。
- **价值**：用一件「被误名为孔明棋」的法国玩具，讲「名字如何迁徙」；与九连环的起源争议、华容道的现代史形成呼应。

### 6.3 玩具模块接口

每个玩具只暴露一个 `PuzzleModule`，共享壳不关心它的内部：

```js
JW.toys.huarong = {
  id: 'huarong',
  title: '华容道',
  subtitle: '搜索',
  levels: JW.data.huarongLevels,

  create(level) { /* 返回初始 state */ },
  clone(state) { /* 深拷贝或结构共享 */ },
  legalMoves(state) { /* 返回 [{ piece, dir, steps }] */ },
  apply(state, move) { /* 返回新 state，不改旧 state */ },
  isWin(state, level) { /* boolean */ },
  solve(state, level) { /* 返回最优 move 列表 */ },
  hint(state, level) { /* 返回一个最优 move + 解释 */ },
  encode(state) { /* 可序列化字符串 */ },
  decode(str) { /* 反序列化 */ },

  mount(root, ctx) { /* 建 DOM/Canvas，绑定事件 */ },
  render(state, ctx) { /* 只重绘，不重建 */ },
  keyboardMap: { /* 键位 → move */ },
  aria(state) { /* 读屏文本 */ },
  stats(state) { /* HUD 数据：步数/距离/覆盖率等 */ }
};
```

约束：

- `state` 必须可 JSON 序列化；撤销 = 状态栈，不做反向操作。
- `solve` / `hint` 必须是纯函数，可在构建脚本/测试页里直接调用。
- 渲染层不写规则；规则层不碰 DOM。
- 每个模块自带 `selftest()`，返回断言列表；`test.html` 汇总执行。

### 6.4 构建：零依赖内联

- `src/build.py` 只用 Python 标准库：读 `src/core/*.js` → 按顺序拼接 → 读 `src/toys/*/*.js` → 读 `src/data/*.js` → 注入 `src/shell.html` → 输出 `dist/index.html`；同时同步 `manifest.webmanifest`、`sw.js` 与 `icons/`，使 `dist/` 可直接作为静态站点根目录。
- 开发时：`python -m http.server 8080`，打开 `dev.html`（逐文件 `<script>` 引入），避免 `file://` 的模块限制。
- 发布时：`dist/index.html` 单文件，无外部请求；`file://` 双击可玩。
- 不引入 bundler、npm、框架；构建脚本 < 200 行，任何人可读。
- 代码用 IIFE + `window.JW` 命名空间，不用 ES module 语法；这样源码也能被普通 `<script>` 直接加载。

## 7. 内容与考据

### 7.1 史实分级

现有文档已经在做「传说/争议」标注，建议升级为四级标签，所有卡片通用：

| 标签 | 含义 | 例 |
|---|---|---|
| **确证** | 有明确文献/实物，年代可考 | 1813《七巧图合璧》；1889 唐芸洲「六子连芳」 |
| **通说** | 学界较通行，但仍有讨论 | 燕几 → 蝶几 → 七巧的演变 |
| **传说** | 民间故事，无实证 | 鲁班/孔明发明鲁班锁；关羽义释曹操 |
| **存疑** | 起源/年代有争议 | 九连环中国起源说；华容道最早布局 |

每条卡片显示标签；图鉴可筛选「只看确证」。这比在正文里写「传说」更清楚，也能防止营销文案越界。

### 7.3 写作规范

- 每张卡：**原文（如有）+ 白话 + 出处 + 考据注 + 标签**。
- 不写「最早」「唯一」「发明」除非有出处；宁写「现存最早之一」。
- 区分「玩具的发明」与「故事的发生」：华容道的故事是三国，玩具是 20 世纪。
- 图像全部重绘；不使用博物馆藏品照片；古籍图形注明来源与公有领域状态。
- 每卷至少 1 张「反常识卡」：华容道不是古代玩具；孔明棋不是孔明发明；鲁班锁没有鲁班实证；七巧板不是一天发明。

## 附录 A · 华容道三种计步的验证记录

本方案在原型阶段用 Python 对 4×5 经典棋盘做了 BFS 复核（仅作可行性验证，不进入发布物）：

- 从「横刀立马」正确布局出发，同形棋子规范化后，所在连通分量可达状态数：**25,955**，与文献一致。
- 「直线步」口径下，曹操到达底部中央的最短步数：**90**，与 Hordern / Tmütze 的 straight moves 一致。
- 「古法 / 指步」81 与「单格步」116 为文献口径；构建时用同一状态图分别建三张距离表复核。
- 若从「曹操已在出口」的全部 6,795 个摆法反向 BFS，会跨过多个连通分量，合计 53,954 个状态；这是「全目标集合」口径，不是单局可达状态数。单局求解必须限制在起点所在分量内。
- 结论：华容道的求解与提示可以在浏览器内 O(1) 完成，不需要服务器。

## 附录 B · 七巧板精确覆盖的离散化

- 以七巧板正方形为 16 个基本等腰直角三角形；每块面积：大三角 4、中三角 2、小三角 1、正方形 2、平行四边形 2。
- 坐标放大 2 倍，所有顶点为整数；每块预计算 8 个朝向（平行四边形另加镜像）。
- 目标剪影栅格化为基本三角形集合；对每块生成「完全落在目标内」的放置；精确覆盖求解。
- 判定条件：每个目标三角形被覆盖恰好一次；总覆盖面积 = 16；无越界。
- 提示：从解中取一块尚未放对的，显示目标位姿；不直接完成。
- **v0.7.0 实现口径**：运行时没有把剪影栅格化，而是直接用连续多边形：剪影 = 参考解七块板多边形的并集；胜利 = 所有板片在剪影内且两两不重叠。面积守恒使「不重叠 + 都在剪影内」等价于精确覆盖。这样既避免三角形栅格的接缝与边界误差，也允许多种解法。上文离散化方案保留作为关卡生成与验证工具的设计。

## 附录 E · 数局的生成、可解性与参考解

- **状态**：长度 `n²` 的数组，`tiles[pos]` 为数字，`0` 为空格；一次移动只交换空格与上下左右相邻数字。
- **生成**：从复原态（`1 … n²−1, 0`）按固定 seed 随机倒走 `depth` 步，且不走回头路；同一 seed 得到同一盘。这样生成的盘面天然可解，不需要「先乱排再判可解」。
- **可解性复核**：按行读数，统计逆序数 `inv`。奇数阶要求 `inv` 为偶；偶数阶要求 `inv + (n − 空格行号)` 为奇（行号从 0 起）。
- **启发式**：`h = 曼哈顿距离 + 线性冲突 × 2`。线性冲突按行、按列分别统计「已在本行/本列但顺序相反」的数字对。
- **搜索**：加权 A*，`f = g + w·h`，默认 `w = 3`；用二叉堆维护开放集，`bestG` 去重。节点上限 3×3 120,000、4×4 350,000、5×5 320,000，超限返回 `limitHit`，不假装成功。
- **为什么不称最优**：十五格最短解本身是 NP-hard 的搜索问题，廿五格更甚；加权 A* 牺牲最优性换响应速度。产品文案统一用「参考解」。
- **实测**（无头 Edge，`dist/index.html`）：4×4 起手参考解约 106 步，5×5 约 98 步，5×5 展开节点约 4.4 万；三档均可在浏览器内归位。
